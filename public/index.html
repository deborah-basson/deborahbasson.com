EPITA · Secure Development course · team of 4 · lead developer

EPITA · systems programming · group project

POSIX-compliant shell written in C99 with no external libraries. Lexer, recursive-descent parser, AST, expansion and execution with fork/exec, pipelines and file descriptor redirections. About 7,800 lines of C and 3,200 functional tests.
